This file describes measured temperature data used in Warren and Bekins 
(2018). The first section describes data files found in DataArchive\ 
subfolder. The second section describes which data file contributed to each 
figure from the results section of the reference. 

Section 1. Data files
----------------------

Data files are in DataArchive\ and are comma-delimited with column headers in 
the first row. Data sources consist of temperature (°C) loggers collecting at 
1-hour (unsaturated zone measurements) or 6-hour (groundwater measurements) 
intervals for 20 July 2013 to 19 July 2014 (inclusive). The locations of the 
observation sites are shown in Figures 1 and 5b of Warren and Bekins (2018).

File name							Contents
---------							---------------------
DataArchiveBackupGroundwater.csv    Groundwater temperatures. The first column
                                    contains the well names, second column 
									contains distances (m) of wells from center
									of source zone. Third column contains 
									average annual temperatures at 0.5 m below 
									water table. The fourth column contains 
									average annual temperatures at 4.0 m below 
									water table.

DataArchiveBackupBkgd1Unsat.csv     Unsaturated zone temperatures at Bkgd1. The
                                    first column contains the elevations (m) of
									the data. The second column contains 
									average annual temperatures (°C).

DataArchiveBackupBkgd2Unsat.csv		Unsaturated zone temperatures at Bkgd2. The
                                    first column contains the elevations (m) of
									the data. The second column contains 
									average annual temperatures (°C).

DataArchiveBackupOil1Unsat.csv      Unsaturated zone temperatures at Oil1. The 
                                    first column contains the elevations (m) 
									of the data. The second column contains 
									average annual temperatures (°C).

DataArchiveBackupOil2Unsat.csv      Unsaturated zone temperatures at Oil2. The 
                                    first column contains the elevations (m) 
									of the data. The second column contains 
									average annual temperatures (°C).
