thermal properties and density and viscosity variation with temperature. Lines 
of code that were changed from published source code are marked with "Ean".

Deletions were accomplished by commenting the line; replacements by commenting 
the old line and adding the new line below; and additions by inserting the line
into the code.

followed by code changes.

!
C     FUNCTION          R  H  O  F  U  N           SUTRA VERSION 3.0       
C                                                                        
C *** PURPOSE :                                                          
C ***  RETURNS A VALUE OF DENSITY BASED ON TEMPERATURE OR CONCENTRATION (U), USING EITHER A LINEAR OR CURVED FUNCTION.
C     
      DOUBLE PRECISION FUNCTION RHOFUN (U) 
      IMPLICIT DOUBLE PRECISION (A-H, O-Z)      
      COMMON /PARAMS/ COMPFL,COMPMA,DRWDU,CW,CS,RHOS,SIGMAW,SIGMAS,
     1   RHOW0,URHOW0,VISC0,PRODF1,PRODS1,PRODF0,PRODS0,CHI1,CHI2
C                                                  
      IF (RHOW0.LT.0D0) THEN                                    
      RHOFUN=DBLE(-1*RHOW0*1000.*(1-(U+288.9414)
     1               *(U-3.9863)**2/(508929.2*(U+68.12063))))
      ELSE                                                          
      RHOFUN = RHOW0+DRWDU*(U-URHOW0)
      END IF 
C                                                                       
      RETURN                                           
      END                   
C                 
!   d/dT 1000*(1-(T+288.9414)*(T-3.9863)^2/(508929.2*(T+68.12063))) =  0.00392982(T-3.9863)(T^2+246.652T+20123.)/(T+68.1206)^2
!
! End New_density
!
C     FUNCTION          V  I  S  C  F  U  N          SUTRA VERSION 3.0       
C                                                                        
C *** PURPOSE :                                                          
C ***  RETURNS A VALUE OF VISCOSITY BASED ON TEMPERATURE (U), USING EITHER A CURVED FUNCTION OR A CONSTANT VALUE 
C ***  DEPENDING ON THE VALUE OF VISC0
C
C *** ML Huber,RA Perkins,A Laesecke,DG Friend,MJ Assael,IN Metaxa,E 
C ***  Vogel,R Mareš,K Miyagawa, New International Formulation for 
C ***  the Viscosity of H2O, J. Phys. Chem. Ref. Data, Vol. 38, 
C ***   No. 2, 2009
!
ccc 1200 VISCG=VISC0*239.4D-7*(10.D0**(248.37D0/(UITERG+133.15D0)))  ! New_density - original code from BASIS       BASIS2.......14300
!
c  VISC0 > 0 - Viscosity units scaling factor (Original method, curved function)
c  VISC0 < 0 - Viscosity of fluid at base temperature (New Linear method)
!
C MOVED FROM BASIS TO A FUNCTION ON SEPT 23,2010 - VOSS AND MCKENZIE
!     
      DOUBLE PRECISION FUNCTION VISCFUN (U)
